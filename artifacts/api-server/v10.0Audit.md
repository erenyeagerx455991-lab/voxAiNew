## Learning Design

- **Trigger**: `learnFromOptimizationResult()` called from `finalizeOptimizationStep()` after build completes
- **Storage**: In-memory `_records[]`, capped at 500
- **Fire-and-forget**: `learnFromOptimization()` is `async` with `.catch()` guard — never blocks pipeline
- **Aggregations**: `buildSuccessRate`, `averageOptimizationScore`, `timeAccuracy`, `costAccuracy`, `byComplexity`, `byModelTier`
- **Hydration**: `hydrateOptimizationLearning(records)` for future disk-load integration

---

## Persistence Design

- **Storage**: `Map<version, OptimizationSnapshot>` in-memory
- **Cap**: 500 snapshots — oldest evicted on overflow
- **Versioning**: monotonically incrementing `_currentVersion`
- **Non-destructive rollback**: returns snapshot without deleting newer versions
- **Never throws**: all methods catch internally and degrade gracefully
- **`capacityUsed` formula**: `total === 0 ? 0 : Math.max(1, Math.round((total / 500) * 100))`

## Agent Optimizer — 23 Agents × 6 Dimensions

Each of the 23 tracked agents receives scores for:
- `efficiency` (0-10) — based on latency vs 5s baseline
- `latency` (0-10) — based on latency vs 8s baseline
- `quality` (0-10) — based on failure rate
- `cost` (0-10) — based on latency/cost proxy
- `successRate` (0-10) — `(1 - failureRate) × 10`
- `confidence` (0-10) — `successRate × 0.9`
- `composite` (0-10) — weighted: efficiency×0.20 + latency×0.15 + quality×0.25 + cost×0.15 + sr×0.15 + confidence×0.10
