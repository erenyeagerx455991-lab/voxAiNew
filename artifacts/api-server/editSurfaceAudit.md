## Quota Gaps Requiring Remediation

- `POST /agents/edit` — makes multiple LLM calls (intent detection + patch generation), no limit enforcement. Must inherit `checkBuildLimit` + concurrent limit + daily token quota.
- `POST /agents/runtime-repair` — makes LLM calls in a repair loop, no limit enforcement.
- `POST /agents/autonomous-build` — makes LLM calls in multi-pass repair, no limit enforcement.

## Enforcement Strategy

Reuse `checkBuildLimit(userId)` as the single source of truth.
`checkBuildLimit()` enforces: concurrent limit, queued limit, daily build quota, daily token quota.
Add `checkTokenBudget()` for global budget check.
No new quota logic — only wire existing systems.
