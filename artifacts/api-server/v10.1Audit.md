## Learning Flow

1. `runMetaStep` executes synchronously and returns the blueprint.
2. After build completes, `finalizeMetaStep` is called by `buildPipeline.ts`.
3. `learnFromMetaResult` creates a `MetaLearningRecord` and calls `learnFromMeta(record).catch(() => {})` — fire-and-forget.
4. `learnFromMeta` appends to a rolling 500-record array.
5. `getMetaLearningStats` computes: avg score, build success rate, avg build time, prediction accuracy, breakdown by complexity and health status.

## Persistence Design

| Property | Value |
|----------|-------|
| Max snapshots | 500 |
| Eviction | Oldest version deleted when cap exceeded |
| Rollback | `rollbackToMetaSnapshot(version)` returns any stored snapshot |
| Threading | Single-process in-memory; no locks needed |
| Failure isolation | All calls wrapped in try/catch; never throws into pipeline |
