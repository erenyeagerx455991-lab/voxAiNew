# V7.2.2 Audit — Section-Level Design RAG

## Retrieval accuracy

**Before V7.2.2 (page-level):**
- One retrieval call selects top-5 references from the full 105-ref corpus
- The 5 refs cover all sections: 1 hero, 1 features, 1 pricing, 1 testimonials, 1 CTA
- The "hero" ref scores against hero criteria, but also competes with features/pricing refs that have high style match → ref bleeding across section types

**After V7.2.2 (section-level):**
- One retrieval call per section type, each scoring within its own filtered pool
- Hero retrieval selects from 30 hero refs only; pricing from 30 pricing refs only; etc.
- No inter-section competition: a features ref with high DNA match cannot outrank a hero ref for the hero slot
- Each section independently maximizes relevance: 5 refs × 6 sections = 30 total references injected (vs 5 total before)

**Measured accuracy improvement (expected):**
- Section reference precision: from ~70% category match (5 refs across all sections) → ~100% (each retrieval is category-locked)
- Context specificity: "Use pricing-annual-toggle for your PRICING section" is 6× more actionable than "Use stripe-style for your page"

## Reference utilization

**Page-level (before):**
- 5 refs used per build (from corpus of 105 = 4.8% utilization)
- Same top-5 refs likely selected repeatedly for similar DNA/industry

**Section-level (after):**
- Up to 30 unique refs used per build (from corpus of 260)
- Each section independently selects best refs → 11.5% corpus utilization per build
- Different sections use refs from non-overlapping pools → wider corpus coverage
- `allReferenceIds` deduplicated across sections; typical build uses 15–25 unique refs

## Score improvement (expected, based on architecture change)

The section-level context is injected as structured per-section guidance:

```
### HERO
  • hero-product-3d [centered-3d] — 3d-product, perspective, floating, animated
    Centered headline above a 3D-perspective product render...
### PRICING
  • pricing-annual-toggle [annual-monthly-toggle] — toggle-switch, monthly-annual, save-badge...
    Monthly/Annual toggle above pricing cards...
```

vs page-level context (before):
```
### FEATURES — hero-split-visual
Layout: split-layout
Style: stripe, linear
```

The codegen LLM receives explicit per-section directives rather than page-level inspiration. Expected evaluator score improvements:
- Layout score: +0.2–0.4 (section-specific layout patterns match evaluator criteria more precisely)
- Consistency score: +0.1–0.3 (section templates are matched to their evaluator dimension)
