## Key Findings

### FINDING 1 — Hero System Excellent (10 variants, 6 layout patterns)

The 10 hero variants cover the major DNA targets with purpose-built structural templates:
- `hero-centered-v1` → Stripe DNA (exact palette hard-coded)
- `hero-asymmetric-v1` → Vercel DNA (monochrome, 2-col terminal)
- `hero-editorial-v1` → Linear DNA (oversized type, bottom bar)
- `hero-bento-v1` → Framer DNA (card mosaic, expressive animation)
- `hero-story-v1` → Agency/light theme (only light-bg hero)

**Gap:** 3 of 7 reference sites have no dedicated hero: Notion (light editorial), Cursor (dev-minimal), Perplexity (academic-clean).

---

### FINDING 2 — Design DNA System Strong (7/7 references, all 17 tokens)

The DESIGN_SYSTEM prompt is the highest-quality specification in the system:
- 7 reference sites each with 17 tokens
- Dominance rules prevent DNA blending
- Anti-patterns explicitly blocked ("NEVER default to purple gradients")
- Industry defaults for 8 types

**Gap:** Industry defaults use plain language (no hex codes) — color accuracy degrades 20% vs reference site paths. Cursor and Perplexity missing from DOMINANCE RULES.

---

### FINDING 3 — Accessibility Is a Systemic Zero

Zero accessibility directives exist across all 7 system prompts. The result:
- 0 ARIA attributes in 75 registry templates
- 0 focus-visible rings anywhere in generated code
- Multiple color contrast failures (white/25, white/30, white/35 on dark backgrounds)
- No form labels in contact/newsletter components
- No heading hierarchy enforcement
- No skip-to-content links

**Impact:** Every website VoxAI generates fails WCAG 2.1 AA. This is not a complex problem — fewer than 20 lines of prompt additions would fix the highest-severity gaps.

**WCAG 2.1 AA Compliance: Fail (2.4/10)**

---

### FINDING 4 — Shadcn Integration is Underdeveloped

Despite shadcn/ui being part of the locked tech stack (ARCHITECTURE_SYSTEM), the actual integration is weak:
- Only 5 of 20+ shadcn components are documented as globals
- 0 of 75 registry templates demonstrate shadcn usage
- CODEFIX_SYSTEM does not preserve shadcn JSX — may corrupt it
- Estimated adoption rate in generated code: 30-40% of applicable sites

**Impact:** Forms, buttons, and interactive elements use raw Tailwind instead of shadcn components, producing inconsistent and less accessible output.

---

### FINDING 5 — Section Routing Is the Most Reliable Dimension (9.2/10)

The Planner's section routing rules are the strongest constraint enforcement in the pipeline:
- Restaurant → Menu, ChefStory, Reservation (never Pricing or FeaturesBento)
- Portfolio → Projects, CaseStudies, Contact (never LogoCloud)
- SaaS → LogoCloud, FeaturesBento, DashboardPreview, Pricing, Testimonials

Scoring 9.2/10 across all 5 benchmark test cases — the highest dimension.

---

### FINDING 6 — Inline Style Violations in 4 Hero Components

ABSOLUTE TECHNICAL RULE 6 prohibits `style={}` objects. 4 hero components use inline styles for dynamic values unavoidable in Tailwind:
- `style={{height: h + 'px'}}` — bar chart heights in hero-dashboard-v1
- `style={{fontSize: 'clamp(52px, 9vw, 128px)'}}` — fluid type in hero-editorial-v1
- `style={{gridTemplateRows: '...'}}` — grid rows in hero-bento-v1

These are structural necessities (Tailwind cannot express dynamic values or clamp without JIT). They should either be whitelisted in CODEFIX_SYSTEM or rewritten using CSS custom properties.

## Conclusions

### What Is Working Well

1. **Reference site DNA system** — the most sophisticated design token system in the codebase; 7 sites × 17 tokens produces authentic visual identities
2. **Hero variant diversity** — 10 heroes with 6 distinct layout patterns; purpose-built for specific DNA targets
3. **Section routing** — highest reliability score (9.2/10); prevents category errors consistently
4. **Code safety rules** — ABSOLUTE TECHNICAL RULES + SAFE CODING RULES V5.2 produce preview-safe code reliably
5. **Structure variation engine** — deterministic seed produces layout variation without random instability
6. **Queue + telemetry infrastructure** — V7.0 scalability foundation is solid; the build pipeline can handle concurrent load

### What Needs Immediate Attention

1. **Accessibility** — zero directives across all prompts; 100% of generated sites fail WCAG 2.1 AA; Tier 1 fixes are 15 lines
2. **Shadcn CODEFIX gap** — CODEFIX may corrupt shadcn JSX; one-line fix
3. **Industry default hex codes** — plain-language palette descriptions produce variable color outputs; hex codes would improve consistency

### What Is a Longer-Term Investment

1. Completing the reference site hero set (Notion, Cursor, Perplexity variants)
2. E-commerce and auth structural templates
3. Accessibility test automation in the CI pipeline
4. Formal visual regression testing
