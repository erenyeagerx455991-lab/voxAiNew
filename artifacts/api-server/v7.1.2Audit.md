## Critical Bug Fixed

**`testimonials-marquee-v1` local `Card` variable conflict**

Before V7.1.2, this template defined `const Card = ({r}) => (...)` which would shadow the global `Card` stub in any generated file that included this template. Any co-generated template in the same file that used `<Card>` would have rendered the local testimonial card component instead of the shadcn Card stub.

Fixed by renaming: `Card` → `TCard` with all usage sites updated.

---

## Constraints and Invariants

1. **Zero pipeline changes** — build route, SSE events, queue, telemetry, agents, RAG, prompts all untouched
2. **No new npm packages** — all stubs are pure React + Tailwind
3. **No iframe sandbox changes** — templates render identically to before; only the component primitives changed
4. **Accordion must use direct child pattern** — `AccordionItem > AccordionTrigger + AccordionContent` (cloneElement constraint)
5. **Tabs active state via TabsContent** — use `TabsContent` for content visibility; `TabsTrigger.onClick` bridge for side effects
