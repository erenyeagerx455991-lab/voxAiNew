## Overview

V8.3 introduces the **Autonomous AI Design Director** — a 25-category static strategic review engine that sits at pipeline **step 11.5** (between Optimization at step 11 and Backend at step 12). It is purely heuristic, no LLM calls, fast and deterministic.

## SSE Events

```
director_start      → { type, agent }
director_review     → { type, overallScore, criticalIssues[3], topRecommendations[3], creativeDirection, confidence, categoryCount }
director_complete   → { type, overallScore, mostCommonProblems[3] }
director_learning   → { type, buildId, overallScore, dnaId, improved }
done                → { ... existing fields ..., directorScore }   ← additive field
```

## Learning Loop

1. `learnFromDirector()` called in `setImmediate` (fire-and-forget)
2. Maps director score → conversionScore proxy
3. Calls `learnFromBuild()` in Design DNA system
4. Director acts as "strategic critic" (`criticScore` = directorScore)
5. `criticalCount > 0` triggers `repairTriggered=true` signal

## Known Limitations

- `mostImprovedCategories` is always `[]` on the initial `DirectorReview` — populated externally by comparing learning history (design decision: no prior-run data required on first build)
- Some conditional categories (pricing, dashboard, forms) return a neutral score (7.5) when not applicable to avoid penalizing sites that don't need them
- Director heuristics are code-pattern–based; false positives possible for unconventional implementations
