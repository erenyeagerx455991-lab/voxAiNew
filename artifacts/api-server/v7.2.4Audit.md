### Phase 6 — Evaluator Coverage Score ✅
**File**: `artifacts/api-server/src/agents/designEvaluator/evaluator.ts`

New `scoreCoverage()` function (lines 322–355):
- Uses `computeComponentCoverage()` to count unique families
- Scoring: `≥14 unique → 10pts`, `≥10 → 8pts`, `≥7 → 6pts`, `≥5 → 4pts`, `≥3 → 2pts`
- Issues emitted when coverage < 50% (major) or < 75% (minor)

Updated weights:
```
Before: { hero: 0.25, layout: 0.20, cta: 0.15, accessibility: 0.20, shadcn: 0.10, consistency: 0.10 }
After:  { hero: 0.25, layout: 0.20, cta: 0.15, accessibility: 0.20, shadcn: 0.08, coverage: 0.07, consistency: 0.05 }
```

`EvaluationResult` now includes:
- `coverageScore: number` (0–10)
- `coveragePercent: number`
- `componentUsage: Record<string, number>`

`scoreShadcn()` upgraded to also reward premium component usage:
- Premium components (Command, DataTable, NavigationMenu, Drawer, HoverCard, Calendar, DatePicker, Menubar): +2pts max bonus
