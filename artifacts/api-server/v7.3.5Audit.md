## 1. System Overview

V7.3.5 implements a **fully autonomous learning loop** for VoxAI's design system:

```
Prompt → DNA → Build → Score → Learn → Improved DNA → Better Future Builds
```

All learning is in-memory (no DB), deterministic, and zero-downtime. The system has no breaking API changes.

## 4. Learning Loop Data Flow

```
Build completes (post-repair, post-conversion)
  ↓
buildPipeline.ts: recordDNAOutcome(evalResult)
  ↓
dnaMetrics.ts: per-dimension quality scores updated
  ↓
Next build:
  plannerStep: buildDNAOptimizationHints() → enriched prompt
  evaluator:   getDNAQualityScore() → dnaQualityScore (dimension 16)
  retriever:   getDNAQualityScore() → dnaQualityBonus (±7.5)
  sectionRetriever: getDNAQualityScore() → dnaQualityBonus (±7.5)
  treeBuilder: getDNAQualityScore() > 7.0 → optional component priority boost
```

## 5. DNA Quality Formula

```
qualityScore =
  overallScore      × 0.35
+ visualScore       × 0.15
+ criticScore       × 0.15
+ conversionScore   × 0.15
+ tokenScore        × 0.05
+ treeScore         × 0.05
+ motionScore       × 0.05
+ (1 - repairRate) × 10 × 0.05

Promotion (+1.5): usageCount ≥ 10 AND avgScore ≥ 9 AND repairRate < 15%
Demotion  (−2.0): avgScore < 7 OR repairRate > 50%
Cold start:  5.0 (neutral — no penalty)
```

---

## 6. DNA Quality Bonus Formula (RAG)

```
dnaQualityBonus = clamp((getDNAQualityScore({primaryBrand}) − 5) × 1.5, −7.5, +7.5)

Cold start: 0 (neutral)
High quality brand (score=9): +6.0 boost
Low quality brand (score=3): −3.0 penalty
DNA/style match (4–9 pts) always dominates
```
