OBJECTIVE

Redesign the entire AI generation engine into an enterprise-grade orchestrated multi-agent architecture inspired by modern AI application builders such as Lovable, Bolt.new, and v0.

This is NOT a chatbot.

This is NOT a sequential prompt chain.

This is an intelligent orchestration engine where every specialized agent performs a dedicated responsibility under a central orchestrator.

The architecture must be modular, deterministic, extensible, observable, and fault tolerant.

=====================================================

GLOBAL PRINCIPLE

The system should never think in terms of prompts.

It should think in terms of work.

Every user request becomes a structured task graph.

Every task becomes independent work.

Every work item is executed by the best specialized agent.

Every output is validated.

Every failure is repaired.

Every successful artifact is merged into one coherent project.

Quality Rules

Never regenerate the whole project if only one file changed.

Never execute unrelated tasks.

Always reuse existing project context.

Always validate before merging.

Always repair before failing.

Always preserve user edits.

Prefer incremental modifications over regeneration.
