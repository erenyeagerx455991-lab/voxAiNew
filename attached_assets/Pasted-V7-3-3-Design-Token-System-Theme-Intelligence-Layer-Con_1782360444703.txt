Current Weakness

Component Tree now exists.

However generators still decide:

- colors
- radius
- shadows
- spacing
- typography
- animation values

individually per build.

This creates:

- inconsistency
- duplicated styling logic
- weaker DNA enforcement
- harder future theming

Goal:

Introduce a Design Token Layer.

New Architecture:

↓
Planner
↓

↓
Component Tree
↓

↓

↓
Generator
↓

↓

↓

Tokens become the single source of truth.
