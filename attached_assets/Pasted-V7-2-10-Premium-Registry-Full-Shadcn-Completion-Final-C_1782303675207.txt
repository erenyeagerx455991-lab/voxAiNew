Phase 2 — Premium Shadcn Rule Engine

Create or update:

"premiumShadcnRules.ts"

Mandatory mappings:

- "button" → "Button"
- "input" → "Input"
- "textarea" → "Textarea"
- "select" → "Select"
- "dialog" → "Dialog"
- "details" / "summary" → "Accordion"
- tabs implementation → "Tabs"
- table → "DataTable"
- dropdown → "DropdownMenu"
- mobile overlay → "Sheet"
- tooltip → "Tooltip"
- loading placeholder → "Skeleton"
- progress bar → "Progress"
- command palette → "Command"
- navigation → "NavigationMenu"

Never allow raw HTML when an equivalent exists.
