V7.0.5 — Real Build Endpoint Load Testing & Throughput Verification

Context

Independent V7.0.4 audit found:

- All previous load tests target "/api/healthz"
- No benchmark exists for "/agents/build"
- Reported 2,488–3,321 req/s numbers measure HTTP health checks only
- Real build throughput remains unknown
- Queue is now active (V7.0.1)
- Token accounting is active (V7.0.2)
- Memory hardening is complete (V7.0.3)

This release exists ONLY to measure actual build capacity.

NO architecture changes.
NO queue changes.
NO AI logic changes.
NO prompt changes.
NO UI work.

Measure reality.

---

Phase 1 — Baseline Capture

Create:

artifacts/api-server/buildLoadBaseline.md

Record:

- Current worker concurrency
- Queue mode (Redis vs in-memory)
- Average build duration from telemetry
- Current queue metrics
- Current token usage metrics

Capture exact values before testing.

---

Phase 2 — Build Load Test Harness

Create:

scripts/load/buildLoadTest.ts

Requirements:

- Target POST /agents/build
- Open real SSE connection
- Wait for completion event
- Measure:
  - queue wait time
  - build duration
  - total request duration
  - success/failure
  - timeout rate

Track:

{
buildId,
startedAt,
completedAt,
queueWaitMs,
buildMs,
totalMs,
success
}

---

Phase 3 — Multi-User Simulation

Support:

- 1 concurrent user
- 3 concurrent users
- 5 concurrent users
- 10 concurrent users
- 25 concurrent users

Each user:

- unique userId
- unique chatId
- independent build request

Do not reuse sessions.

---

Phase 4 — SSE Validation

Verify:

Every build receives:

- queued
- started
- step events
- completed OR failed

Detect:

- dropped streams
- duplicate events
- out-of-order events

Produce failure report.

---

Phase 5 — Queue Analysis

Measure:

- average queue wait
- p50 queue wait
- p95 queue wait
- max queue wait

Record queue depth during test.

Answer:

At what concurrency does queueing begin?

---

Phase 6 — Worker Capacity Analysis

Measure:

- builds/minute
- average build time
- p50 build time
- p95 build time
- max build time

Calculate:

effective throughput =
completed_builds / test_duration

Use actual completed builds only.
