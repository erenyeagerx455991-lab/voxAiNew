Phase 12 — Thin Orchestrator

Create:

runBuildPipeline()

Responsibilities ONLY:

const plan = await runPlannerStep();

const architecture =
  await runArchitectureStep(plan);

const frontend =
  await runFrontendStep(architecture);

const backend =
  await runBackendStep(architecture);

const repaired =
  await runRepairStep(frontend, backend);

return runRuntimeValidationStep(repaired);

Target:

<150 LOC

No business logic allowed.

Only orchestration.
