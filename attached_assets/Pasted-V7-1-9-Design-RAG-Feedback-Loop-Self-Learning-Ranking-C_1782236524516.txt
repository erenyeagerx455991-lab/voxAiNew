V7.1.9 — Design RAG Feedback Loop + Self-Learning Ranking

Context

V7.1.8 complete.

Verified working:

- Design RAG corpus active (104 references)
- Retriever active
- Design DNA active
- Design Evaluator Agent active
- Auto Repair Loop active
- Component Intelligence active
- Quality telemetry active
- 591/591 tests passing

Current limitation:

Design RAG retrieval is still static.

Retriever ranks references using:

- DNA match
- Category match
- Layout match
- Quality metadata

But it does NOT learn from actual build outcomes.

Result:

A reference that consistently generates 9.5/10 builds is treated almost the same as one that generates 7.0/10 builds.

This prevents the system from improving itself over time.

---

Goal

Transform Design RAG from:

Static Retrieval

into

Self-Improving Retrieval

Where:

Build
↓
Evaluator
↓
Repair
↓
Reference Performance Tracking
↓
Reference Ranking Update
↓
Better Retrieval

without changing:

- queue
- providers
- evaluator scoring
- repair logic
- SSE formats
- frontend behavior

---

PHASE 1 — Reference Performance Store

Create:

src/design-rag/referenceMetrics.ts

Every DesignReference must track:

id
usageCount
successCount
repairCount
averageScore
averageScoreAfterRepair
averageRetrievalImpact
lastUsedAt

Rules:

usageCount++

every retrieval usage

successCount++

when final score >= 8.5

repairCount++

when repair loop triggered

No estimates.

Only real evaluator results.

---

PHASE 2 — Retrieval Impact Tracking

Track:

retrievalImpact

Formula:

scoreAfterRepair

scoreBeforeRepair

Store rolling average.

Example:

Reference A:

avg impact +1.4

Reference B:

avg impact +0.2

Reference A should rank higher.

---

PHASE 3 — Dynamic Reference Quality Score

Create:

referenceQualityScore

Formula:

averageScoreAfterRepair * 0.40
+
successRate * 0.25
+
(1 - repairRate) * 0.20
+
retrievalImpact * 0.15

Normalize:

0–10

Store per reference.

---

PHASE 4 — Retriever Upgrade

Modify:

src/design-rag/retriever.ts

Current ranking:

DNA
+
Category
+
Layout

New ranking:

DNA
+
Category
+
Layout
+
referenceQualityScore

Rules:

Quality score must influence ranking.

But:

DNA match remains dominant.

Never allow:

poor DNA match
+
high score

to outrank

perfect DNA match.

---

PHASE 5 — Auto Promotion

References automatically move upward when:

usageCount >= 5

AND

averageScoreAfterRepair >= 9

AND

repairRate < 15%

Promote priority.

---

PHASE 6 — Auto Demotion

References automatically move downward when:

usageCount >= 5

AND

averageScoreAfterRepair < 7

OR

repairRate > 50%

Demote priority.
