NexoGen V6.6 — Registry V2 + RAG Retrieval Architecture

Objective

Replace full registry prompt injection with Retrieval-Augmented Generation (RAG).

Current system injects the entire component catalogue into planner/frontend prompts.

This must be replaced with:

User Prompt
↓
Intent Analysis
↓
Registry Retrieval Engine
↓
Top-K Components
↓
Prompt Builder
↓
Frontend Generation

Only relevant components should enter the LLM context.
