---

PHASE 1 — Shadcn-First Generation Rules

Upgrade all generation prompts.

Every generated page must prefer:

- Button
- Card
- Badge
- Accordion
- Tabs
- Avatar
- Separator
- Input
- Dialog
- Sheet
- Tooltip
- DropdownMenu
- Progress
- Skeleton

before creating custom HTML.

Rule:

Never generate raw button markup when Button component exists.

Never generate custom accordion when Accordion exists.

Never generate custom tabs when Tabs exists.

---

PHASE 2 — Typography System

Create mandatory typography hierarchy.

Hero:

- text-5xl minimum desktop
- text-4xl minimum tablet
- text-3xl minimum mobile

Section Titles:

- text-3xl

Card Titles:

- text-xl

Body:

- text-base

Small text:

- text-sm

Rules:

No arbitrary text sizing.

No text-xs for content.

No inconsistent typography scales.

---

PHASE 3 — Spacing System

Enforce 8pt grid.

Allowed spacing:

- 4
- 8
- 12
- 16
- 24
- 32
- 48
- 64
- 96

Disallow random spacing.

Examples:

Avoid:

- p-7
- mt-11
- gap-13

Prefer:

- p-8
- mt-12
- gap-6

---

PHASE 4 — Color Discipline

Rules:

Maximum:

- 1 primary color
- 1 accent color

Disallow:

- rainbow gradients
- multi-accent UI
- 5-color cards

Allow:

Stripe:

- Indigo + Violet

Linear:

- Neutral + Purple

Vercel:

- Neutral + White

Apple:

- Neutral + Blue

Framer:

- Purple + Pink

---

PHASE 5 — Motion System

All animations must use Framer Motion.

Allowed:

- fade
- slide
- scale
- stagger

Disallow:

- spinning elements
- bouncing elements
- excessive parallax

Animation duration:

150–400ms only.

---

PHASE 6 — Layout Intelligence

Every page must follow:

Hero
↓
Features
↓
Trust
↓
Proof
↓
CTA

Rules:

No repeated section categories.

No duplicate layouts back-to-back.

No 3 consecutive card grids.

---

PHASE 7 — Accessibility Foundation

Every generated component must include:

Buttons:

- type="button"

Links:

- focus-visible:ring

Forms:

- label + htmlFor

Icons:

- aria-hidden="true"

FAQ:

- aria-expanded

Navigation:

- aria-label
