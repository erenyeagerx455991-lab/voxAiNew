V7.3.5 — Self-Evolving Design DNA Engine

Objective

Build a fully autonomous Design DNA learning system that continuously improves design decisions using evaluator scores, critic scores, visual quality scores, conversion signals, section outcomes, and component performance.

The goal is:

Current System:
Prompt → DNA → Build → Score

New System:
Prompt → DNA → Build → Score → Learn → Improved DNA → Better Future Builds

This system must never change existing APIs, SSE events, queues, providers, or generation flow.

Phase 3 — DNA Quality Formula

Create:

calculateDNAQuality()

Formula:

qualityScore =
overallScore × 0.35

+ visualScore × 0.15
+ criticScore × 0.15
+ conversionScore × 0.15
+ tokenScore × 0.05
+ treeScore × 0.05
+ motionScore × 0.05
+ (1 - repairRate) × 10 × 0.05

Normalize to:

0–10

New DNA entries start at:

5.0

No cold-start penalty.

Phase 4 — Promotion Engine

Automatically promote successful DNA patterns.

Requirements:

usageCount >= 10

AND

averageScore >= 9

AND

repairRate < 15%

Promotion:

priorityBonus += 1.5

Record promotion history.

Fully reversible.

---

Phase 5 — Demotion Engine

Automatically demote weak DNA patterns.

Conditions:

usageCount >= 10

AND

averageScore < 7

OR

repairRate > 50%

Penalty:

priorityPenalty -= 2.0

Fully reversible.

Never permanently ban a DNA.
