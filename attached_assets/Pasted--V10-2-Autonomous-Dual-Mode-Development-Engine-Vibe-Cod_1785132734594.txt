# V10.2 — Autonomous Dual-Mode Development Engine (Vibe Coding + Manual Coding)

## Objective

Build V10.2 Autonomous Dual-Mode Development Engine.

The objective is to transform NexoGen from an AI-only vibe coding platform into a complete software development platform where users can:

1. Build entire applications using AI (Vibe Coding).
2. Write code manually.
3. Mix AI-generated code with handwritten code.
4. Switch between AI and manual development at any time.
5. Keep both modes synchronized automatically.
6. Never lose manual edits after AI regeneration.
7. Preserve architecture, state, dependencies, routing, APIs, database, and project consistency.

This engine must work like Cursor + Lovable + VS Code combined.

---

# CRITICAL REQUIREMENTS

This engine MUST NOT replace existing generation.

It extends the platform.

Existing AI generation remains unchanged.

Instead, after AI generates a project, the user receives a complete IDE inside the browser.

The IDE becomes the permanent workspace.

Everything afterwards happens inside that workspace.
