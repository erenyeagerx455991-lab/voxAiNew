Current Weakness

All scoring is currently:

- code-based
- component-based
- token-based
- architecture-based

The system cannot see the actual rendered UI.

This means:

- broken layouts can pass
- spacing bugs can pass
- overflow issues can pass
- alignment issues can pass
- visual hierarchy problems can pass
- repair agent can accidentally degrade visuals

Goal:

Add visual intelligence.
