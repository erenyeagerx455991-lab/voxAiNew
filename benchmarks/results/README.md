# Benchmark Results

Directory structure for V7.2.1 competitive benchmark results.

## Structure

```
benchmarks/results/
  voxai/          ← VoxAI build outputs (generated by benchmarkRunner.ts)
  lovable/        ← Lovable outputs (captured manually)
  bolt/           ← Bolt outputs (captured manually)
  v0/             ← v0 outputs (captured manually)
```

Each provider directory contains one JSON file per benchmark prompt:

```
{promptId}.json   e.g. saas-001.json
```

## Capturing VoxAI Results

```bash
# From workspace root
cd artifacts/api-server
pnpm exec tsx src/benchmarks/benchmarkRunner.ts
```

## Capturing Competitor Results

1. Open the competitor tool (Lovable, Bolt, or v0)
2. Paste the prompt from `benchmarks/prompts/benchmark-dataset.json`
3. Export the generated HTML
4. Save to `benchmarks/results/{provider}/{promptId}.html`
5. Run the import script:

```typescript
import { importCompetitorResult } from '../src/benchmarks/benchmarkRunner.ts';
const html = fs.readFileSync('benchmarks/results/lovable/saas-001.html', 'utf-8');
await importCompetitorResult('lovable', 'saas-001', 'SaaS', html);
```
